● CORRECT - Test set is ONLY for evaluation, NOT for improvement!

  This is a fundamental machine learning principle:

  Test Set Purpose

  Test set = Honest exam
  - ✓ Measures how well model works on NEW/UNSEEN data
  - ✓ Tells you if model will work in real world
  - ✗ Does NOT contribute to training/improvement
  - ✗ Should NEVER be used for training

  Why Keep Test Separate?

  Scenario 1: Train on ALL data (no test set)
  Result: 100% accuracy!
  Problem: You don't know if it works on NEW photos
           Maybe it just memorized the training photos?

  Scenario 2: Train + Test split (current approach)
  Train set: OC-SVM learns what "authentic" looks like
  Test set:  Check if OC-SVM recognizes NEW authentic photos

  If test accuracy is high → Model generalizes well!
  If test accuracy is low → Model is overfitting (just memorizing)

  Real-World Example

  Your workflow:
  1. Train on 60% of photos (train set)
  2. OC-SVM learns "authentic" features from these
  3. Test on 20% of photos (test set) - these photos were NEVER seen during
  training
  4. If test accuracy is good → You can trust it will work on future new photos

  Test set is like a practice exam - you don't study from the exam questions, 
  you use it to check if your studying worked!

  After Testing - What Improves the Model?

  To actually improve:
  1. Add MORE training photos (more diverse captures)
  2. Train for more epochs
  3. Adjust model architecture
  4. Then re-test on the SAME held-out test set

  The test set stays constant - it's your "benchmark" to measure improvement.
