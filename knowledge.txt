1. PAPER SUMMARY
================================================================================
Title: "Mobile authentication of copy detection patterns: how critical is to know fakes?"
Authors: Olga Taran, et al., University of Geneva
Paper: http://sip.unige.ch/articles/2021/Taran_WIFS2021.pdf

KEY CONCEPTS:
- CDP (Copy Detection Patterns) = Printable graphical codes for anti-counterfeiting
- Acts as Physical Unclonable Functions (PUFs)
- Links physical and digital worlds
- Printed codes are sensitive to illegal copying

PAPER'S DATASET (Indigo Mobile):
- 300 distinct DataMatrix digital templates (330×330, symbol size 5×5)
- Printed on: HP Indigo 5500 DS at 812 dpi (industrial printer)
- Captured with: iPhone XS at 12MP under regular lighting
- 300 original captures
- 1200 fake captures (4 types):
  * Fakes #1 white: RICOH MP C307 on white paper
  * Fakes #1 gray: RICOH MP C307 on gray paper
  * Fakes #2 white: Samsung CLX-6220FX on white paper
  * Fakes #2 gray: Samsung CLX-6220FX on gray paper

TWO AUTHENTICATION APPROACHES:

A) SUPERVISED CLASSIFICATION (Baseline)
   - Requires: Both originals AND fakes for training
   - Trains binary classifier to distinguish original from fake
   - Result: If trained on high-quality fakes, can detect unseen medium-quality fakes
   - Problem: If trained only on medium-quality fakes, CANNOT detect high-quality fakes
   - Accuracy: Near perfect when all fake types available during training

B) ONE-CLASS CLASSIFICATION (Main Focus)
   - Requires: ONLY originals for training (no fakes needed!)
   - Architecture: Auto-encoder x → t̂ → x̂
     * x = input image (phone photo)
     * t̂ = estimated digital template
     * x̂ = reconstructed image

   - Loss function: L = -I(X;T) - β·I(T;X)
     Where:
     * I(X;T) = mutual information between image and template
     * I(T;X) = mutual information between template and reconstructed image
     * β = weight balancing the two terms

   - Two variants:
     * L¹ (Dtt_Dxx): Uses only reconstruction terms
     * L² (Dtt_Dt_Dxx_Dx): Adds KL-divergence regularizers

   - Feature extraction:
     * dist_t = Hamming distance between real template (t) and estimated template (t̂)
     * dist_x = MSE between real image (x) and reconstructed image (x̂)

   - Classification: OC-SVM (One-Class Support Vector Machine)
     * Trained on features from originals only
     * Detects anomalies (fakes) based on distance from original distribution

PAPER'S KEY FINDINGS:
- Modern mobile phones + ML enable CDP authentication under unknown fakes
- One-class classification works well even without knowledge of fakes
- Setup (4) L²_One-class with {Dtt, Dxx} features achieves lowest error (0.14% ±0.32%)

   Step 1: Train
   $ python ./supervised_classification/train.py --epochs 100

   - Loads originals + fakes from data/
   - Trains binary classifier to distinguish them
   - Saves weights to: checkpoints/rgb_supervised_classifier_n_2/

   $ python ./supervised_classification/test.py --epoch 100

   - Loads trained classifier weights
   - Tests on all data (originals + fakes)

B) ONE-CLASS CLASSIFICATION WORKFLOW (Recommended):

   Step 1: Train Feature Extraction Model
   $ python ./one_class_classification/train_Dtt_Dxx.py --epochs 100

   - Loads ONLY originals from data/original/rgb/
   - Trains encoder-decoder: x → t̂ → x̂
   - Saves weights to: checkpoints/rgb_Dtt_Dxx/EstimationModel_epoch_100

   Step 2: Extract Features
   $ python ./one_class_classification/test_Dtt_Dxx.py --epoch 100 --subset test

   - Loads trained encoder-decoder
   - Processes each image:
     * Estimates template: t̂ = encoder(x)
     * Reconstructs image: x̂ = decoder(t̂)
     * Calculates distances: [dist_t, dist_x]
   - Saves features to: results/Dtt_Dxx/test_rgb_Dtt_Dxx.txt (JSON format)

   Example JSON output:
   [
     [[10.5, 0.0012], [12.3, 0.0015], ...],  # Originals: [dist_t, dist_x]
     [[150.2, 0.0028], ...],                  # Fakes #1 white
     [[145.8, 0.0026], ...],                  # Fakes #1 gray
     ...
   ]

   Step 3: Train OC-SVM and Test
   $ python ./one_class_classification/oc-svm_Dtt_Dxx.py

   - Loads extracted features from JSON
   - Trains OC-SVM on ONLY original features
   - Tests on all samples (originals + fakes)
   - Outputs:
     * Classification errors per class
     * Visualization plot (decision boundary)
   - Saves to: results/Dtt_Dxx/oc-svm_rgb_Dtt_Dxx.pdf

   COMBINED COMMAND (runs Step 2 and 3 together):
   $ python ./one_class_classification/test_Dtt_Dxx.py && python ./one_class_classification/oc-svm_Dtt_Dxx.py

   The "&&" means: "Run first command, and IF it succeeds, run second command"

7. KEY TECHNICAL CONCEPTS
================================================================================

WHAT IS CDP?
- Copy Detection Pattern
- Printable graphical code (like QR code, but for authentication)
- Contains random pattern that's hard to copy perfectly
- Printing + scanning introduces degradation
- Original vs fake can be distinguished by analyzing this degradation

DATAMATRIX:
- Type of 2D barcode (ISO/IEC 16022)
- Used as the CDP template in this project
- Square grid of black/white cells
- Symbol size 5×5 means each "bit" is printed as 5×5 pixels

FEATURE EXTRACTION (x → t̂ → x̂):
1. Encoder: Photo (x) → Estimated template (t̂)
   - U-Net architecture
   - Learns to "decode" what the original template was

2. Decoder: Estimated template (t̂) → Reconstructed image (x̂)
   - U-Net architecture
   - Learns to "re-print" the template as it would appear in photo

3. Features:
   - dist_t = Hamming distance: How many bits differ between real template (t) and estimated (t̂)
   - dist_x = MSE: Pixel-wise difference between real photo (x) and reconstructed (x̂)

   For originals: Both distances should be SMALL
   For fakes: Distances will be LARGER (harder to estimate/reconstruct correctly)

ONE-CLASS SVM:
- Learns the "boundary" around original samples in feature space
- Only needs originals for training
- At test time:
  * Inside boundary → Original
  * Outside boundary → Fake
- Uses RBF kernel, nu=0.0005, gamma=0.1

================================================================================
FEATURE VALUES INTERPRETATION
================================================================================

Example features from your 3 photos:
Photo 1: [dist_t: 1911.16, dist_x: 0.0024]
Photo 2: [dist_t: 1879.60, dist_x: 0.0027]
Photo 3: [dist_t: 1925.92, dist_x: 0.0024]

WHAT THESE MEAN:

dist_t (Hamming Distance):
- Measures: How many bits differ between real template and estimated template
- For originals: Usually 1500-2500 bits (depends on print/scan quality)
- For fakes: Usually HIGHER (harder to estimate correctly)
- Your values (~1880-1925): Normal for originals

dist_x (MSE - Mean Squared Error):
- Measures: Pixel difference between real photo and reconstructed photo
- For originals: Usually 0.001-0.005
- For fakes: Usually HIGHER (harder to reconstruct correctly)
- Your values (~0.0024-0.0027): Good for originals

OC-SVM DECISION BOUNDARY:
- OC-SVM learns a boundary around original features in 2D space (dist_t, dist_x)
- Inside boundary -> Classified as Original
- Outside boundary -> Classified as Fake
- Your 3 photos should all be inside the boundary
